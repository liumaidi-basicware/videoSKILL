# UGC 开箱场景

## 适用场景

客户需要"开箱体验"风格视频——从拆包装到第一次使用的全过程，重点展示
产品外观、细节和第一印象。转化率介于测评和硬广之间，适合新品上市。

## 脚本约束

### 结构模板

```
钩子（"刚到货，一起拆开看看"）
→ 拆封过程（包装 → 配件 → 主体，手部特写为主）
→ 第一印象（外观质感、重量、细节）
→ 首次使用（一个核心功能的实际操作）
→ 自然收尾（"总体感觉 XX，后续再用一段时间告诉大家"）
```

### 字数与时长

| 类型 | 字数 | 时长 |
|---|---|---|
| 标准开箱 | 80-200 词 | 30-60s |
| 快速开箱 | 40-80 词 | 15-30s |
| 深度开箱 | 200-400 词 | 60-90s |

### 文案要求

- 全程第一人称，口吻是"分享"不是"推销"
- 拆封段允许语气词（"哦""嗯""这个不错"）
- 必须包含至少 1 个"超出预期"和 1 个"小遗憾"的对比
- CTA 是软性的（"感兴趣可以看看"），不做硬广价格/促销信息

## 产品板强绑定

### 九宫格产品板的 UGC 扩展

开箱场景的产品九宫格板须包含以下 9 格（而非标准产品板配置）：

| 格位 | 内容 | 构图 |
|---|---|---|
| 1 | 包装整体 | 平铺俯拍 |
| 2 | 拆开封条瞬间 | 手部 + 封条特写 |
| 3 | 盒内全景 | 俯拍开盒 |
| 4 | 配件阵列 | 平铺排列 |
| 5 | 产品正面 | 45° 俯拍 |
| 6 | 产品背面/细节 | 微距特写 |
| 7 | 材质/手感特写 | 侧光局部 |
| 8 | 首次操作/点亮 | 使用状态 |
| 9 | 全家福 | 产品 + 配件 + 包装合影 |

### 产品使用图

开箱场景的 `product_usage` 图（铁律 4 的人物产品使用细节图）须展示：
- 手部从盒中取出产品的动作
- 产品在手中的比例感（手作参照物）
- 至少一个功能操作特写

## 数字人板要求

### 手部特写锁定

```json
{
  "shot_style": "handheld_pov",
  "hand_visibility": "frequent",
  "nail_style": "natural",
  "accessories_on_hand": "none",
  "sleeve_length": "rolled_up",
  "camera_distance": "extreme_close_up_for_details"
}
```

### 场景约束

- 桌面须有自然杂乱感（咖啡杯、便签等道具），不做影棚白底
- 光源为台灯或自然侧光，不用影视灯
- 背景须有生活化物品（书架、厨房用品等）

## 故事板约束

- 动态格数故事板中**手部特写约占 1/3 或更多**
- 产品九宫格板中的格 2/6/7 须在故事板中出现
- 不允许"数字人正面证件照"格——开箱全程以手和产品为主
- 最后 2 格须有"上手使用"画面

## 视频生成参数

```json
{
  "video_type": 5,
  "ratio": "9:16",
  "duration": 45,
  "negative_prompt": "studio lighting, green screen, logo watermark, text overlay, professional advertisement, corporate style"
}
```

> video_type=5（多图同框）因为开箱需要同时引用人物板 + 产品板 + 场景图。

## 质检补充

- 产品板须通过 `product-consistency` skill 的指纹校验
- 故事板须确认手部特写格数 ≥ 4
- OCR 闸门须特别关注包装文字残留（产品名/参数标签）
- take_review 的 `marketing.product_visibility` 维度须为 True
